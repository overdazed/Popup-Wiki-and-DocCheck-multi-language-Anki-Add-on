# Popup-Wiki and Doccheck (multi-language) Anki Add-on
An updated version of the Anki add-on **"Popup-Wiki and Doccheck (multi-language)"** updated to support **Qt6 / PyQt6** and modern Anki versions (Anki 23.10+ / 24+ / 26+).

## Credits
* **Original Add-on:** [Popup-Wiki and Doccheck (multi-language)](https://ankiweb.net/shared/info/482393989) on AnkiWeb.
* **Original Functionality:** Created for integration of Wikipedia & DocCheck Flexikon directly within Anki.

## Features
* Look up highlighted terms in **DocCheck Flexikon** or **Wikipedia** directly via the right-click context menu.
* Side panel inside Anki so you don't have to leave the app while reviewing cards.
* Configurable Wikipedia language (e.g., `de`, `en`).

## Installation

Since this is an updated version for modern Anki / PyQt6, you can install it manually:

1. Click on the green **"Code"** button at the top of this repository and select **"Download ZIP"**.
2. Unzip the downloaded archive.
3. Open Anki and go to **Tools** > **Add-ons**.
4. Click on **"Open Add-ons Folder"**.
5. Move the unzipped folder into your Anki add-ons directory.
6. Restart Anki.
