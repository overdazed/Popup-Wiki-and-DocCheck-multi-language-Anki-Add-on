# Popup-Wiki and Doccheck (multi-language) Anki Add-on
An updated version of the Anki add-on **"Popup-Wiki and Doccheck (multi-language)"** updated to support modern Anki versions (Anki 23.10+ / 24+ / 26+).

## Credits
* **Original Add-on:** [Popup-Wiki and Doccheck (multi-language)](https://ankiweb.net/shared/info/482393989) on AnkiWeb.
* **Original Functionality:** Created for integration of Wikipedia & DocCheck Flexikon directly within Anki.

## Features
* Look up highlighted terms in **DocCheck Flexikon** or **Wikipedia** directly via the right-click context menu.
* Side panel inside Anki so you don't have to leave the app while reviewing cards.
* Configurable Wikipedia language (e.g., `de`, `en`).

## Installation

Since this is an updated version for modern Anki, you can install it manually:

1. Go to the **Releases** section on the right side of this repository.
2. Download the ready-to-use `.zip` file from the latest release.
3. Unzip the archive directly into your Anki add-ons directory:
   * Open Anki and go to **Tools** > **Add-ons**.
   * Click on **"Open Add-ons Folder"**.
   * Move the unzipped folder into this directory.
4. Restart Anki.
